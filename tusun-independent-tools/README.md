# 兔狲独立版工具下载页

本页展示严格按制作流程排序的七款 macOS 独立版工具。中心 App 不计入 01–07，也不在本页提供中心或工作坊安装包；当前 01–07 均已提供经过核验的公开下载入口。01、02、03、05、07 为授权公开内测包，04、06 为公开内部候选；所有可下载包均未完成 Developer ID 正式签名和 Apple 公证，部分工具也尚未完成真实付费生成验收，页面按产品逐项披露该状态。

官方 Logo 复制自同一站点 `tusun-film-center/assets/` 的七份已固定网页资产。产品名与功能说明沿用兔狲中心的正式展示目录。版本、Build、系统要求、文件大小和 SHA-256 来自各自当前公开资产或对应本机最终候选；页面当前列出的 01 剧本编辑器和 07 视频工作台独立版资产托管在中心工具 release 中，但仍是独立包，不是中心 App 或工作坊包。02 批量图生成台页面当前提供 DMG 手动安装入口；其 updater 清单另指向同版本 ZIP，二者校验值不能混用。

运行检查：

```bash
python3 -m unittest tusun-independent-tools/test_download_page.py -v
```

本地预览：

```bash
python3 -m http.server 4173
```

当某款工具的公开资产发生替换时，只更新该工具的版本、包型、大小、SHA-256 和经过匿名访问验证的独立版 HTTPS URL；不要把 updater ZIP 的 SHA-256 填到 DMG 卡片，也不要把工作坊包或中心 App 混入 01–07。测试会拒绝任意包含 `workshop`、`Workshop` 或“工作坊”的工具下载链接，并确保页面保持固定的 01–07 流程顺序。
